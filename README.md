# 🎬 CineMatch AI — AI-Powered Movie Discovery & Recommendation Platform

> *“Find your mood. Discover your movie. Make every watch worth it.”*

CineMatch AI is an intelligent movie discovery platform combining cutting-edge Web Animations, an interactive 3D particle morphing AI orb, and WebGL authentication.

---

## ✨ Features

- **7.3s Master-Clock Cinematic Hero (/)**:
  - Center-splitting lacquer doors
  - Skyscraper rooftop pool camera tilt into the glowing rainy skyline
  - 4-layer parallax stage with dual-video crossfading continuous rain loop
  - Letter-by-letter synchronized "Summit" typography reveal
- **AI Thinking Orb Chatbot (/chat)**:
  - 3D particle canvas math simulation with vortex dynamics and light sweep routines
  - Interactive phases: *Analyzing mood*, *Scanning TMDB*, *Matching themes*, *Composing recommendation*
  - Grounded movie recommendations with explainable AI rationales and compatibility match scoring
  - Quick mood chips (Drama, Thriller, Sci-Fi, Crowd Pleaser, Romance, Visually Stunning)
- **Modern WebGL Authentication (/auth)**:
  - Procedural 3D dot shader matrix with GLSL uniforms and golden ratio math
  - Sign in / Sign up switching with email and social auth buttons (Google, GitHub, Apple)

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, TypeScript, Tailwind CSS
- **Graphics & 3D**: Three.js, Custom WebGL ShaderMaterial, Canvas 2D Physics
- **Icons & Routing**: Lucide React, React Router DOM
